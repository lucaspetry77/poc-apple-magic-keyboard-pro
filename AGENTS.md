# Projeto

Este é um site estático satírico em português. Preserve o design, os renders e a piada do vibe coding. HTML em `index.html`, JavaScript em `src/app.js`, CSS em `src/styles.css`.

- Use `npm ci`, `npm run dev`, `npm run check`, `npm run build` e `npm run preview`.
- Vite é ferramenta de desenvolvimento/build; não introduza um framework para ajustes pontuais.
- O chat é uma demonstração local e a compra é conceitual. Preserve esses comportamentos.
- Referencie somente WebPs de `public/assets/` na página. Originais e prompts ficam em `design/`.
- Após uma alteração visual, revise o build no navegador e confira telas de 390 e 360 pixels, foco, teclado e os estados afetados.
- Documente a mudança e a validação realizada. Não trate o build ou a CI como prova de comportamento em um iPhone físico.
