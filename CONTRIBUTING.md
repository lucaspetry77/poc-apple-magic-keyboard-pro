# Contribuir

1. Execute `npm ci` e `npm run dev`.
2. Edite o conteúdo em `index.html`, os estilos em `src/styles.css` e as interações em `src/app.js`.
3. Mantenha a copy em português, o tom comercial satírico e o produto com duas teclas.
4. Use WebPs em `public/assets/`; guarde PNGs e prompts em `design/`.
5. Rode `npm run format`, `npm run check` e `npm run build`.
6. Confira o build com `npm run preview`, incluindo 390 e 360 pixels de largura, navegação por teclado e os estados afetados.

Em um PR, descreva o comportamento alterado, inclua uma imagem quando o visual mudar e informe a validação realizada. Preserve o funcionamento local da demo e da compra conceitual.
